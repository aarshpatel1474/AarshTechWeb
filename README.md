# Aarsh Tech Web — Official Android Apps & Games Studio

Official developer portfolio and showcase website for **Aarsh Tech Web**, showcasing published Google Play mobile applications and games.

## 🚀 Published Applications on Google Play

1. **Tic Tac Toe : 2 Player XO & AI**
   - **Package ID:** `com.aarsh.tictactoe`
   - **Google Play:** [View on Play Store](https://play.google.com/store/apps/details?id=com.aarsh.tictactoe&hl=en_IN)

## 💻 Tech Stack & Getting Started

- **Framework:** React 19 + Vite 8
- **Icons:** Lucide React
- **Celebration Effects:** Canvas Confetti
- **Linter:** Oxlint

### Run Locally:
```bash
# Start development server
npm run dev

# Lint codebase (0 warnings, 0 errors)
npm run lint

# Compile production build to /dist
npm run build
```
